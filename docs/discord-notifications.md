# Уведомления в Discord

Сайт умеет отправлять два вида уведомлений:

1. **Личные сообщения** игроку, если он привязал Discord в настройках профиля.
2. **События в канал** через вебхук: заказы, сделки маркета, рассылки.

## Настройка

В `.env`:

```bash
# Вебхук канала для событий (если пусто, используется DISCORD_WEBHOOK_URL)
DISCORD_EVENTS_WEBHOOK_URL=

# Токен бота — нужен для личных сообщений
DISCORD_BOT_TOKEN=

# Публичный адрес сайта для ссылок в уведомлениях
WEBSITE_URL=
```

Вебхук создаётся в Discord: **Настройки канала → Интеграции → Вебхуки**.
Бот для ЛС — приложение в [Developer Portal](https://discord.com/developers/applications);
у бота должен быть доступ к общим серверам с игроком.

## Когда отправляются

| Событие | ЛС игроку | Канал |
|---|---|---|
| Заказ магазина выдан | да | да |
| Заказ магазина возвращён | да | да |
| Продажа на маркете | продавцу | да |
| Покупка на маркете | покупателю | да |
| Достижение | через чат-мост | — |
| Рассылка из админки | — | да (если включено) |

Все уведомления необязательные: если токен или вебхук не заданы, функции
молча ничего не делают. Таймаут запроса к Discord — 3 секунды, чтобы сайт
не зависал.

## Привязка Discord

Игрок привязывает аккаунт в `/profile/settings` через OAuth
(`DISCORD_CLIENT_ID` и `DISCORD_CLIENT_SECRET`). ID сохраняется в
`users.discord_id`. Если привязки нет, личные сообщения не отправляются.
