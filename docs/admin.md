# Админка

Доступ только у пользователя с `users.role = "admin"` (владелец сервера).
Модераторов и банов нет.

## Разделы

| Раздел | Что делает |
|---|---|
| `/admin` | сводка и ссылки |
| `/admin/users` | выдача и снятие прав администратора, балансы |
| `/admin/seasons` | создание, правка и активация сезонов |
| `/admin/shop` | товары, цены, лимиты, ручная выдача заказов |
| `/admin/analytics` | просмотры разделов и мёртвые страницы |
| `/admin/economy` | массовые начисления BLD/фишек и оборот валют |
| `/admin/broadcast` | уведомление всем игрокам (сайт, чат, Discord) |
| `/admin/audit` | журнал действий администратора |
| `/admin/content` | подписи и видимость фото, текст записей стены |
| `/inventory` | инвентарь игроков и откат снимков |

## Аудит

Каждое важное действие пишется в `admin_audit`: роль, сезон, товар,
выдача заказа, валюта, массовое начисление, рассылка, правка контента.
Журнал доступен в `/admin/audit` и не редактируется из интерфейса.

## Рассылка

Заголовок до 120 символов, текст до 1000. Уведомление получают все
зарегистрированные игроки. Галочки «в чат» и «в Discord» необязательны.

## Экономика

Массовое начисление или списание работает по всем игрокам, только по
игрокам или только по админам. Баланс не уходит ниже нуля, каждое
изменение попадает в `wallet_ledger` и в уведомления.
